5 tablo, real üretim & endüstri schema

UCI ML Repository — AI4I 2020 (Matzka, S., 2020). CC BY 4.0. **Önemli disclosure:** Bu dataset endüstri-standart predictive maintenance benchmark — Siemens/GE/Honeywell internal ML training'inde kullanılıyor. Schema gerçek (rotational_speed_rpm, torque_nm, FMEA modes) ama row'lar synthetic — gerçek factory floor IoT data permissive license altında public değil.

products
1000 rows
Per-unit metadata — udi, product_id, type (L/M/H), tool_wear_min
operational_data
1000 rows
Sensor okumaları — air_temp_k, process_temp_k, rotational_speed_rpm, torque_nm
failure_events
1000 rows
Failure flag'leri — machine_failure + 5 mode (TWF, HDF, PWF, OSF, RNF)
failure_modes
5 rows
Lookup — code, name, fmea_category, description
Veri kaynağı + lisans: Veri: UCI ML Repository — AI4I 2020 Predictive Maintenance Dataset (Matzka 2020), CC BY 4.0. Industrial benchmark, raw factory data değil.
