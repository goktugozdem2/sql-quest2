# 2026-09-23: the app shell is one noindex page, but the site links it under
# 1,105 different query strings (/app/?challenge=…&src=…, ?company=…&goal=…),
# and Bing's own recommendation read "Your site has limited crawl capacity"
# while 2.9K IndexNow submissions produced 85 crawls. Every parameterised
# app URL is the same shell; crawling it only spends the budget the question
# and company pages need. /app/ itself stays crawlable (it is noindex).
