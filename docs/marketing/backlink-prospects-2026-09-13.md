# SQL Quest: backlink outreach prospect list

## Method

- **Date:** 2026-09-13. Research only. Nobody was contacted and nothing in the repo was changed.
- **Tools:** WebSearch (US index), WebFetch.
- **Core queries:**
  - Q1 `best SQL practice websites`
  - Q2 `best SQL interview websites`
  - Q3 `SQL interview preparation tools`
  - Q4 `DataLemur alternatives`
  - Q5 `best sites to learn SQL`
  - Q6 `StrataScratch alternatives`
  - Q7 `LeetCode SQL alternatives`
  - Q8 `websites to practice SQL for data analyst interview`
- **Variants run:**
  - Q1b `best websites to practice SQL 2026`
  - Q1c `free SQL practice websites for beginners list`
  - Q1d `top SQL practice platforms roundup blog`
  - Q2b `best SQL interview practice platforms 2026`
  - Q3b `SQL interview preparation tools 2026 data analyst`
  - Q4b `DataLemur alternatives free 2026`
  - Q5b `best sites to learn SQL 2026 free`
  - Q6b `StrataScratch vs DataLemur vs LeetCode comparison 2026`
  - Q7b `LeetCode SQL alternatives for data analysts free`, `"LeetCode alternatives" SQL data engineering 2026`
  - QR `reddit best website to practice SQL for interviews`, `site:reddit.com …` (two forms)
  - QQ `quora best website to practice SQL queries`
  - QG `awesome sql github list practice resources`, `github awesome interview prep data science SQL …`
  - QX misc: `"HackerRank SQL" alternatives`, `"websites to practice SQL" hackernoon OR freecodecamp …`, `class central best SQL practice resources`, `best SQL learning apps 2026 ranked`, `SQL interview practice tools with AI feedback 2026`
- **Paging:** The search tool returns one page of about 6–10 results and does not page. The variants above stand in for page 2.
- **Position:** "pos" is the rank inside that query's result block, so treat it as approximate.
- **Reddit:** No reddit.com URL came back for any query, including `site:reddit.com`. The index returned Blind (teamblind.com) threads instead, and those are listed.
- **Excluded:**
  - Vendor homepages and product pages (datalemur.com, stratascratch.com, leetcode.com, hackerrank.com, sql-practice.online homepage, pgexercises.com)
  - SEO traffic tools (semrush, similarweb, sitelike, siteprice)
  - Scribd uploads and GitHub topic pages
  - SQL Quest's own pages (sqlquest.app)
  - sql-quest.app, a different product
  - developerindian.com: the account is suspended, so the page is dead
- **Result:** 100 unique URLs.
  - 68 were fetched.
  - 32 could not be fetched (Medium, Quora, LinkedIn posts, HackerNoon, Class Central, some Blind threads, Interview Query and DataInterview rate-limited, geo-ict certificate error, sql.solutions 403). Those rows use the search snippet and say "not fetched".
- **SQL Quest already mentioned:** 2 of 100 (AlternativeTo's DataLemur and SQL Noir pages). None of the editorial roundups mention it.
- **Vendor-owned roundups:** Pages run by StrataScratch, DataLemur, Interview Query, SQLPad, PracHub, DataInterview, SQLMarrow and similar sites are listed so the list is complete. They are scored 1–2 because a competitor will not add SQL Quest.
- **Contact details:** Only what the page or author profile shows publicly. No email address was guessed.
- **Fit score:**
  - 5 = recent, lists 5+ SQL tools, editable or maintained, clear contact route
  - 1 = competitor-owned or dead

Abbreviations in the "Tools listed" column: DL DataLemur, SS StrataScratch, LC LeetCode, HR HackerRank, IQ Interview Query, W3 W3Schools, SZ SQLZoo, SB SQLBolt, KA Khan Academy, DC DataCamp, CA Codecademy, KG Kaggle, PGX PostgreSQL Exercises.
