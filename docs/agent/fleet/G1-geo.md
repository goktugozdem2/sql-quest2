# G1 — GEO (generative engine optimization): being found by AI tools

**Lane:** whether ChatGPT, Gemini, Perplexity, Copilot and Claude name and cite
SQL Quest when a person asks a buyer question, and the site-wide plumbing
that decides it. **Laptop**: it needs a browser, web search and the
first-party AI landings.
**Cadence:** weekly measurement on Wednesdays; fixes in between.
**Judged by:**
- **share of voice**: of the prompt panel below, how many answers name or
  cite sqlquest.app, per engine, week on week;
- `ai:*` landings per month (`landingSrc`).

**Split with C2.** G1 measures and owns the site-wide plumbing. C2 owns what
a page says (the answer-first summaries). G1 hands page-level gaps to C2 as
BACKLOG lines.

## Why (founder, 2026-11-22: "AI toolları bizi de yakalayabilsin")

- Two of the first payers came through AI assistants. A payer wrote that
  Gemini sent him "straight to" SQL Quest. These assistants strip the
  referrer, so most of this traffic hides in `direct/none` (617 people in the
  7 days to 11-22).
- Chat-shaped GSC queries ("давай", pasted exam questions) show assistants
  grounding on our trap pages.
- Assistants retrieve through search indexes (ChatGPT and Copilot use Bing,
  Gemini uses Google), so C1's Bing recovery (#138) is GEO work too.

## Each Wednesday run

1. **Measure, per engine, per prompt.** Record whether SQL Quest is named,
   which of our URLs are cited, and which competitors are named. Keep only
   the cited URLs and names; never copy whole answers.
   - **Perplexity: monthly, not weekly (founder, 2026-11-25).** Since
     11-25 perplexity.ai asks for a sign-in on the first query, so the
     weekly no-sign-in rotation cannot run. Weekly runs skip it and mark it
     "not read" (never a miss). Once a month (the first Wednesday) it joins
     the monthly founder check below: list the 5 prompts for him to run
     signed in and say where to record what he sees. Never sign in yourself.
   - **Grounding proxy for ChatGPT and Copilot**: Bing results for the same
     prompt (WebSearch, or `bing_stats` queries). Where we rank in Bing's
     top 10 is the pool those assistants cite from.
   - **Grounding proxy for Gemini**: Google position from `gsc_daily` for
     the matching queries.
   - **ChatGPT, Gemini, Claude and Copilot themselves need the founder's
     sign-in.** Never sign in, never use his sessions. Once a month, list the
     5 prompts for him to paste and say where to record what he sees.
   - Bing Webmaster's **AI Performance** panel (Copilot citations) has no
     API. Ask the founder for the monthly number.
2. **Write the table** to `docs/reads/geo-<date>.md`: prompt × engine,
   named / cited URL / competitors named, and the change since last week.
   The share-of-voice line goes on top.
3. **Fix the plumbing** in a code PR for A1 → A0, source only:
   - `/llms.txt` (generated by `scripts/build-llms-txt.js`): entry points,
     facts with dates, counts from helpers.
   - structured data: `Organization`, `SoftwareApplication` /
     `WebApplication`, `FAQPage` that matches the visible FAQ verbatim
     (`tests/faq-schema.test.js`), `Dataset` where we publish data. One
     consistent entity name ("SQL Quest"), one URL, one description.
   - crawler access: `robots.txt` must keep GPTBot, ClaudeBot,
     PerplexityBot, Google-Extended and Bingbot allowed on content pages.
     A blocked AI crawler is the first thing to check after any robots
     change.
   - comparison pages: competitor facts only from a dated `docs/reads/`
     file (C2/B6 own the facts).
4. **Off-site mentions.** Write each gap as a BACKLOG line for C3, which
   drafts and stays behind the founder. A gap is a list, a Reddit or Q&A
   thread, or a "best SQL practice sites" article that assistants cite for a
   panel prompt and that does not name us. Never post, comment or contact
   anyone.

## Rules

- No claims about competitors beyond a dated read. No "most-asked" or
  frequency claims (CLAUDE.md SEO rules).
- No customer data in the repo.
- Respect each engine's terms. One query per prompt per week, with no
  scraping loops and no automation around a sign-in or a CAPTCHA. If an
  engine asks for a sign-in or a CAPTCHA, stop on that engine and note it.
- A `noop` week is fine: report the table and change nothing.
