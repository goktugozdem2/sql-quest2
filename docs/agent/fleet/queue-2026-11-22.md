# Fleet task queue — start 2026-11-22

The founder's order (2026-11-22): "Ajanların görev listesi hazırla, çalışmaya
başlasınlar. Durma." This file is the first queue. Each line is one run of one
agent, written as a task the agent can finish in one session. The orchestrator
works top to bottom inside each runtime and ticks a line off with its PR number.

Two runtimes, because they reach different things:

- **Cloud** (claude.ai/code sessions): the repo, build, tests, headless Chrome
  against a local `public/`. **No production data and no sqlquest.app** (the
  proxy refuses the host, measured 2026-11-22). Cloud runs open PRs and never
  merge.
- **Laptop** (the main loop, `sqlquest-autodev-loop`): read-only Supabase,
  GSC/Bing tables, Gmail, the live site, `mergeone.sh`. Everything that needs a
  number or a person runs here.

Budgets from `README.md` hold across both: at most 2 code agents at once, about
15 merges a day.
