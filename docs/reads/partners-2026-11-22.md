## 4. The pitch I would change

1. **Lead with the free cohort pilot, not seats.** No price appears in any
   message. The pilot has a stated size (25 learners for one bootcamp cohort,
   40 for a college class for one semester), seats are set up by hand, and the
   teacher gets a weekly note. A seat price comes after a pilot shows
   something, once the founder has confirmed the price option.
2. **Open with their learners' interview moment, not our features.** WBS's
   curriculum itself promises SQL interview prep; SPTech guarantees an
   internship whose door is often a SQL screen. One fact about them, one
   question.
3. **Say the dialect difference up front** (SQLite vs MySQL / BigQuery /
   PostgreSQL). A teacher finds it in five minutes anyway; saying it first
   is what makes the rest credible.
4. **Prefer warm over well-fitting.** Referrer evidence beats a ranked list.
5. **Smaller batches, sent the same week.** Two drafts, not five; re-read the
   page on the day of writing.

## 5. Decisions for the founder

- **The seat price.** The repo records that on 2026-09-26 the founder picked
  Option B: $39 a seat for a 3-month cohort pass, 10-seat minimum, with the
  weekly per-learner summary (commit `41171763`,
  `docs/outreach/teams-2026-09-26.md` §2). This run's brief says no price
  option has been picked. Until the founder confirms which is true, P1
  quotes no price and offers only the free pilot.
- **Whether to publish `/for-teams/`.** It states no price, so it does not
  wait on the price decision. The 30-day kill rule in row 6 of the
  monetization plan starts only when the page is published and linked;
  unlinked, it can never fail and never pass. Recommendation: publish it
  with one footer link ("For teams") and start the 30-day clock. That is a
  code change for the page's owning lane, not P1.
- **Send the two Gmail drafts** (WBS Coding School, SPTech), on different
  days. P1's rule: if nothing has been sent by 2026-11-29, P1 stops writing
  new drafts and keeps only qualifying and reply handling.
