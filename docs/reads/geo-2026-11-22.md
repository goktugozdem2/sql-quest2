## Plumbing audit

**robots.txt is fine.**
- GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-User, Claude-SearchBot, PerplexityBot, Perplexity-User, Google-Extended, anthropic-ai and bingbot are all `Allow: /`.
- Only the bundles, `/api/` and the parameterised app shell are disallowed.
- The live file equals the repo.
- A fetch of `/sql-exercises/` with each AI crawler's user agent answers 200.

**Structured data had one split entity. It is fixed in the code PR.**
- **Valid:** every JSON-LD block on `/`, `/sql-practice-comparison/`, `/best-sql-practice-sites/` and `/sql-exercises/` parses, and the FAQPage blocks are already bound to the visible FAQ (`tests/faq-schema.test.js`).
- **Inconsistent:**
  - The homepage `Organization` carries `@id …/#organization`. But the comparison pages' `author` / `publisher`, the `/sql-exercises/` `Course` provider and four providers on the homepage were bare `{name: "SQL Quest"}` nodes, with no `@id` and no `url`.
  - The `SoftwareApplication` said `https://sqlquest.app` (no slash) and had no publisher.
  - The homepage `Course` and the `WebSite` `SearchAction` pointed at `/app.html`, which is a 308.
  - The `SearchAction` advertised a `?q=` search that the app does not read.
- **Observation, not changed:** the `alternateName` list includes "SQLQuest". `src/index.html` itself notes that this is another product's exact name (a SQL game at sql-quest.app). For an assistant it is a disambiguation risk. Removing it is the founder's call (FOUNDER below).

**llms.txt was silent on the buyer questions. It is fixed in the code PR.**
- It had entry points, facts and a full page list, but not the panel's questions in a person's words. The PR adds "Questions people ask, and the page that answers": all 15 panel prompts, each with the existing pages that answer it.
