## How the config sees the repo

- **Entries:** `src/app.jsx` and `src/pg-mode/entry.js` come in through
  knip's Vite plugin (the two `lib.entry`s in `vite.config.js` and
  `vite.pg-mode.config.js`). The other entries are set by hand:
  - `src/track.js` and `src/blog-quiz.js`: pages load these through a
    `<script src>`.
  - `src/data/*.js`: concatenated into `public/data.js` by
    `scripts/bundle-data.js` from the `dataFiles` list. They are never
    imported; they work as `window.*` globals.
  - `api/*.js`: Vercel functions.
  - `tests/**`.
- **Scripts:** knip finds the scripts that `package.json` and
  `.github/workflows/*.yml` run (its npm-scripts and GitHub Actions
  plugins), plus anything those scripts or the tests import. A script run
  only by hand therefore shows up as an "unused file".
- **Out of scope:** `supabase/functions/**` (Deno, its own import map) and
  `public/**` (build output). Neither is in `project`, so knip never
  reads them.
- **Ignored after checking each one:**

  | Ignored | Why |
  |---|---|
  | `@babel/preset-react` | Only `build:jsx:babel` uses it, as a CLI `--presets` argument, which knip cannot see. |
  | `playwright` | `scripts/smoke/uiux-audit.mjs` `require`s it inside a try/catch. `uiux-daily.yml` installs it with `npm i --no-save`, on purpose. |
  | `ruby` (binary) | `tests/deploy-prod.test.js` parses YAML through the system ruby. |
